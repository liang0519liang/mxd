# 风险、故障处理与待确认清单

## 必须由用户/实际测试确认

1. 目标怀旧服的服务条款是否允许本项目所定义的屏幕采集和常规输入自动化；未确认则只能做检测/调试。
2. 窗口标题关键字、客户区真实尺寸、Windows 缩放比例、是否独占全屏、窗口是否必须前台。
3. 首个角色、地图、怪物外观、UI 皮肤、语言、分辨率、ROI 与训练数据覆盖范围。
4. 攻击/瞬移/Buff 的键位、是否要方向前置、单键按住语义、冷却、施法前后延迟、实际攻击范围。
5. 普通移动每个脉冲位移、瞬移实际落点分布、目标选择阈值、允许连续次数。
6. 宠物自动拾取实际半径、等待时长、掉落物视觉消失延迟，以及“消失”是否可作为可接受的代理验证。
7. 可接受的漏检、误报、响应时间、FPS、GPU/CPU 占用和保存日志/截图策略。

## 风险与缓解

|风险/警告|缓解与安全动作|
|---|---|
|窗口/ROI/DPI 坐标偏差|显示双坐标矩形；启动校验 ROI；异常即 PAUSED、释放键。|
|模型漏检或误报|覆盖训练数据、每类阈值、时间确认；不基于单帧清怪或玩家消失行动。|
|小掉落物难识别|提高标注质量/分辨率，必要时增大 ROI 推理尺寸；不能把未检测到等同拾取成功。|
|输入失控/冲突|控制器唯一出口、资源排他、短脉冲、所有异常/退出/失焦 release_all_keys。|
|瞬移过头/技能时序差|有限次数、冷却、settle、重新定位；未经实测不启用。|
|UI 卡顿|检测后台线程、有界最新帧队列、UI 定时拉取。|
|显存不足|batch 下调优先，再下调图像尺寸；记录环境与 CUDA 版本。|
|长时间运行退化|日志轮转、内存/队列监控、故障注入和 soak test。|

## 运行期故障语义

- `PAUSED`：可恢复的外部安全条件（失焦/最小化/用户暂停）；释放所有键，恢复必须先 RELOCALIZE。
- `ERROR`：异常、动作反复超时或急停；释放所有键，不自动恢复旧动作，需人工开始新的安全会话。
- `LOOT_UNCONFIRMED`：经过和等待后视觉仍未给出可靠消失证据；不是“已拾取”。
- `LOOT_ABANDONED`：达到有限尝试/队列超时；记录原因后退出该物品，防止无限循环。
