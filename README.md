# MapleStory 怀旧服 YOLO 视觉自动化辅助系统

> **Phase 0 — 方案与实施计划**
>
> 本仓库当前只交付技术方案、配置设计和分阶段验收计划；**不包含**实际按键控制、模型训练或游戏自动化代码。后续实施仅限游戏规则和服务条款允许的视觉采集与常规输入模拟范围，明确不包含进程注入、内存读写/修改或反作弊绕过。

## 已知需求

- Windows 上对标题关键字匹配的游戏窗口进行客户区采集；ROI 相对客户区定义，窗口移动后自动重算。
- 使用轻量 YOLO 检测 `player`、`monster`、`loot`，以检测框底部中心作为横向平台距离估计点。
- 控制逻辑以最新视觉结果和有限短脉冲为依据；默认 `DRY_RUN=True`，所有按键经单一控制器并可安全释放。
- 需要 FSM 协调接近、瞬移、攻击、Buff 与掉落物巡检，并提供独立的实时调试界面、日志、暂停和紧急停止。
- 宠物拾取不模拟拾取键：角色只在掉落物附近经过并等待可配置时间，再以视觉消失作为有限的验证信号。

## 硬件适配结论

i7-10700、RTX 3060 12GB、16GB 内存足以完成本项目的本地轻量模型训练与 1366×768 窗口 ROI 的实时推理。首轮推荐从 Ultralytics YOLO 的 **nano/small 检测模型**开始，推理 ROI 采用 640 像素量级；训练先尝试 640 图像尺寸、batch 8–16，并以 CUDA 显存实际占用为准调整。模型版本、实际 FPS、batch 和图像尺寸均属于待实测参数，不能在 Phase 0 承诺固定数值。
